# To-Do Service API

The To-Do Service is a cloud-hosted task list where subscribers add tasks and receive reminders.

## API reference docs

Detailed resource descriptions for the service.

The API reference docs use `{base_url}` when they refer to the URL of a resource.
The value of `{base_url}` depends on the installation of the service.

When you run the service locally for testing, `{base_url}` is usually `http://localhost:3000`.

* [user resource](https://uwc2-apidoc.github.io/to-do-service-au26/api/user/)
* [task resource](https://uwc2-apidoc.github.io/to-do-service-au26/api/task/)
