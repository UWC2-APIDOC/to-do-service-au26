# Markdown overview

## Introduction

Markdown is a portable format and renders the same when displayed
across different apps. It's simple as there are fewer options and
it's easy to learn. It's software-agnostic, so it doesn't lock
your content to a certain environment. Also, Markdown
files are easy to search, parse, and index, making them work
with AI.

While there are some limits, you can present many of the
formatting options a WYSIWYG editing tool offers, such as:

- Different heading sizes

- _Italics_, **bold**, and ~~strike through~~

- Quoted text, for example:

> Quoted text block quotes

- `Inline code`

- ```markdown

    codeblocks

- and more.

## Instructions - text formatting feature options

| Feature | Method | Example |
| ------ | ------- | --- |
| Bold | `**text**` or `__text__` double underscore | **text** |
| Italics | `_text_` | _text_ |
| Both bold and italics | `**_text_**` | **_text_** |
| Strike through | `~~text~~` | ~~text~~ |
| Inline code | ` `` ` backticks | `text` |

---

## Drawbacks

Markdown doesn't natively support many formatting options
freely used in word processors or other apps.
It doesn't support changing font colors or size (outside
of headers), underlining text, different text
alignments, image positioning, or the ability
to use columns. It also lacks means to
embed video or other media. Table styling, alignment, and
ease of editing or moving content within is also lacking.
